# Vitrio 4.4

Nova tela **Mensagens do pedido**:

- O lojista pode personalizar uma mensagem para cada status:
  - Pedido confirmado
  - Em preparação
  - Pedido pronto
  - Saiu para entrega
  - Pedido concluído
- Variáveis disponíveis:
  - `{cliente}`
  - `{pedido}`
  - `{loja}`
  - `{total}`
- É possível ativar/desativar o recurso.
- Cada cartão mostra uma prévia da mensagem.
- Há botão para restaurar o texto padrão.
- As mensagens são salvas no documento da loja.
- Na tela de Pedidos, após mudar o status, o Vitrio abre a conversa do WhatsApp do cliente com a mensagem correspondente pronta.
- Também existe botão manual **Enviar WhatsApp** em cada pedido.
