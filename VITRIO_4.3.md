# Vitrio 4.3

Correção na página Entregas:

- O campo da taxa de entrega não converte mais o valor para número a cada tecla.
- Agora é possível apagar o zero e digitar normalmente.
- O valor só é convertido ao salvar a região.
- Aceita valores como `10`, `10.50` e `10,50`.
- Após adicionar a região, o campo volta vazio para o próximo cadastro.
